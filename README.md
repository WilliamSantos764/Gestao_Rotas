# Gestão de Rotas e Entregas

Sistema em HTML para organização de rotas de entrega de segunda a sexta-feira.

## Funcionalidades atuais

- Rotas separadas por dia da semana
- Busca por cidade
- Filtro por dia
- Adição de novas cidades e rotas
- Edição de rotas
- Remoção de cidades
- Exclusão de rotas
- Salvamento automático no navegador
- Restauração da configuração original
- Estrutura preparada para integração com ESPD
- Estrutura preparada para distribuição em caminhões

## Como usar

Basta abrir o arquivo `index.html` no navegador.

## Publicar com GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos deste projeto.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve.

Após alguns instantes, o GitHub disponibilizará um endereço público para o sistema.
